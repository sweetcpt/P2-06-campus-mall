# P2-06 参考成品式实验平台设计

## 目标

把现有 P2-06 校园商城从“参与端 + 后台”两页成品，补成参考成品 `Kesuburigi_HomeWork` 所示的完整网络营销 A/B 实验平台切片：有首页总览、项目页、实验工作台、参与登记、真实商城行为、汇总分析、接口配置和可部署入口。

## 必须保留

- P2-06 唯一核心变量仍是“免运费门槛提示：无提示 vs 进度条提示”。
- A/B 两组商品、价格、购物车、结算和推荐内容保持一致；B 只额外展示免邮进度与低价凑单入口。
- 初始商品为 USB 小风扇 ¥39.90，配送费 ¥6.00，免邮门槛 ¥53.00。
- 样本来自真实参与者的商城操作；不生成随机模拟样本，不伪造结果。
- 刷新时参与者版本稳定，预览模式不写正式数据，正式参与者不因刷新重复计入。
- 页面继续支持 GitHub Pages 子路径，后端继续支持 Cloudflare Worker + D1，并保留离线本机回退。

## 参考成品式页面结构

### `index.html`：平台首页

使用参考成品的深色实验平台外壳，包含湛江科技学院/粤西地域设定、P2 项目入口、实验规则、个人进度和参与端入口。首页不直接承担购物车逻辑。

### `project2.html`：项目二页

展示“校园商城小程序与私域社群转化”项目说明和 P2-06 实验卡片。卡片进入 `experiment.html?id=P2-06`，另提供参与端和汇总页入口。

### `experiment.html?id=P2-06`：实验工作台

按参考成品的 ①—⑤ 模块组织：

1. A/B 两版方案：使用商城/购物车手机样式预览，展示真实 P2-06 变量。
2. 实时实验数据：从记录计算 A/B 人数、完成数、平均最终商品金额、差值、相对变化和样本提醒；没有样本时明确显示“暂无数据”。
3. 邀请参与：生成参与 URL、复制链接、生成可保存的简单分享卡片，并引导使用 `share.html?e=P2-06`。
4. 数据收集：显示本机/云端数据源、导入答卷/行为包、接口配置和清空入口。
5. 结论与解读：只输出描述性统计；样本不足时不宣布显著胜出，提供课程报告可用的限制说明。

### `share.html?e=P2-06`：参与登记入口

沿用参考成品“先登记身份再开始”的流程，收集学号、姓名、班级后创建参与会话，再进入 `shop.html`。这些字段只用于课程实验答卷去重和汇总展示，不采集支付、手机号或其他个人资料。正式版本明确告知这是模拟购物，不产生真实订单。

### `shop.html`：真实商城参与端

承接现有 `index.html` 的真实购物车逻辑和视觉资产：初始化 USB 小风扇，允许加购/减购/打开购物车/结算。实验版本由稳定会话决定，B 版显示动态免邮提示。行为记录带上登记资料、participant_id、variant、初始/最终金额和件数、继续加购、免邮达成、结算点击等字段。

### `aggregate.html`：汇总统计

采用参考成品的统计页结构，至少包括自动汇总状态、总参与者/有效答卷/选择或行为数量、A/B 指标对比、按班级分布、参与者明细、P2-06 逐记录明细和 CSV 导出。云端不可用时明确回退本机数据。

### `setup.html` 与 `admin.html`

`setup.html` 提供 Worker URL、实验 key、后台口令的保存和健康检查入口；`admin.html` 保留现有后台作为 P2-06 快速入口，并链接到工作台和汇总页，避免破坏已发布链接。

## 数据与接口

- 前端本机记录继续使用 localStorage，正式记录按 `participantId + studyKey` 去重。
- 参与登记资料进入记录/答卷对象，并在导出时使用 CSV 正确转义。
- Worker POST 继续使用单条记录 upsert；GET 返回完整记录；状态单调更新，旧客户端 payload 不得清空新字段。
- D1 增加 `student_id`、`participant_name`、`class_name` 字段，并保留现有行为字段迁移兼容。
- `assets/config.js` 默认 API 为空；未配置时页面仍可完整演示，并在工作台显示本机模式。

## 视觉方向

- 参考站的暗色背景、深灰卡片、细边框、蓝/橙/绿色语义色、圆角和数字网格。
- 参与商城仍保留手机优先与真实购物感；实验平台页面采用参考站的工作台层级，不把随机模拟数据或假结论放入正式结果。
- 所有资源使用相对路径，手机宽度 375/390/430 与 GitHub Pages 子路径必须正常。

## 验收标准

- 参考平台链路页面可从首页逐级进入，链接和子路径无 404。
- 新参与者登记后能稳定进入一个版本；刷新不会变版，也不会重复新增样本。
- A/B 购物行为、数据字段、汇总指标和 CSV 均由真实本机/云端记录派生。
- 预览 A/B 仅展示，不产生正式记录。
- 无样本时工作台显示空状态；小样本时不伪造显著性结论。
- `node tests/smoke.mjs`、全部 JS 语法检查、浏览器链路和 375/390/430 响应式检查通过。
